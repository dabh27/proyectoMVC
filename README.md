GESTIÓN DE USUARIOS - PROYECTO MVC

Este proyecto es una aplicación web simple para la gestión de usuarios, desarrollada siguiendo el patrón MVC (Modelo-Vista-Controlador). Utiliza Node.js como servidor, MySQL como base de datos, y HTML, CSS y JavaScript para la interfaz de usuario.

FUNCIONALIDADES

Crear usuarios: Un formulario permite agregar nuevos usuarios ingresando su nombre y correo electrónico.
Listar usuarios: Muestra una lista de todos los usuarios almacenados en la base de datos.
Actualizar usuarios: Permite modificar los datos de un usuario existente.
Eliminar usuarios: Permite eliminar usuarios de la base de datos.

TECNOLOGIAS UTILIZADAS

Backend:
- Node.js
- Express.js
- MySQL

Frontend:
- HTML5
- CSS3 (Estilos modernos y responsivos)
- JavaScript (manejo dinámico de eventos)
  
Base de datos:
- MySQL

¿CÓMO EJECUTAR EL PROYECTO?
1. Clona el repositorio:

git clone <URL_DEL_REPOSITORIO>

cd <NOMBRE_DEL_REPOSITORIO>

2. Instala las dependencias:

npm install

3. Configura la base de datos:

- Crea una base de datos en MySQL.
- Actualiza las credenciales de conexión en config/database.js.

4. Inicia el servidor:

node server.js

5. Accede a la aplicación: Abre tu navegador en http://localhost:3002.
